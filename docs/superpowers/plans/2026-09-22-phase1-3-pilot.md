# Phase 1–3 Pilot Implementation Plan (base stack + tooling + `cleantest` / `clean-automator`)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task (inline; the work mutates one machine and needs the user's sudo password in their terminal, so per-task subagents are the wrong tool). Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Stand up Laravel Valet + Homebrew PHP 8.4/7.4 + mysql@8.4 + Mailpit next to the still-running MAMP PRO, build the repo tooling, and migrate exactly two disposable sites (`cleantest`, `clean-automator`) end to end.

**Architecture:** Inventory is data (`sites.tsv`); `bin/lib.sh` holds shared helpers; `bin/migrate-site` is one idempotent per-site pipeline (link → isolate → secure → DB → DB_HOST → search-replace → mu-plugin → smoke); `bootstrap.sh` makes the machine ready and is the only thing a teammate runs. Sites are linked explicitly from the inventory, never parked, so `automator-platform` is never served.

**Tech Stack:** bash (`set -euo pipefail`), jq (macOS `/usr/bin/jq`), Homebrew, Laravel Valet 4.12, WP-CLI 2.12 (phar, invoked with an explicit PHP binary), mysql@8.4, Mailpit, PHP for the mu-plugin/driver/dashboard.

**Spec:** `docs/mamp-to-valet-migration-handoff-v2.md` (sections 4, 5, 6, 6.1, 9.1, 9.3, 9.7, 10, 11).

## Global Constraints

- No Docker for WordPress. Homebrew formulae / native binaries only.
- Default PHP `php@8.4`; `php@7.4` from `shivammathur/php` for `automator-docs`, `elearning-docs`, `clean-automator`.
- DB engine `mysql@8.4`, default port 3306, default socket; `DB_HOST` becomes `127.0.0.1` on every migrated site.
- Sites are **linked** (`valet link <host>`), not parked. `automator-platform` is out of scope and never linked.
- `uncanny-automator` is protected: `migrate-all` skips it; `migrate-site` refuses without `--i-have-a-backup`. This plan does **not** touch it, nor any site other than `cleantest` and `clean-automator`.
- MAMP PRO keeps running throughout. Nothing under `/Applications/MAMP` or in MAMP's MySQL is modified or deleted. Mail from migrated sites goes to MAMP's MailHog on 1025 until Mailpit can bind (same SMTP port).
- Every script is idempotent; a second run is a no-op.
- PHP files: WordPress coding style, tabs, Yoda conditions. Shell: `set -euo pipefail`, `--json` where output is consumed by tooling.
- Verification here is "run the command, compare output" (infra, not unit tests). Each task ends with a commit on `main`; push at the end of Task 10.
- Nothing from `~/.zshrc` other than the PATH line is printed or changed (it contains a token).

```bash
#!/usr/bin/env bash
# Shared helpers for local-devstack bin/ scripts. Source, do not execute.
set -euo pipefail

REPO_DIR="$(cd "$(dirname "${BASH_SOURCE[0]}")/.." && pwd)"
SITES_DIR="${SITES_DIR:-$HOME/Sites}"
SITES_TSV="${SITES_TSV:-$REPO_DIR/sites.tsv}"
LOG_DIR="${LOG_DIR:-$HOME/migration-log}"
VALET_HOME="${VALET_HOME:-$HOME/.config/valet}"
VALET_BIN="${VALET_BIN:-$HOME/.composer/vendor/bin/valet}"
BREW_PREFIX="${BREW_PREFIX:-$(brew --prefix)}"
DEFAULT_PHP="${DEFAULT_PHP:-php@8.4}"
TLD="${TLD:-test}"

# MAMP PRO's MySQL 8.0 (source of the data). Read-only use.
MAMP_MYSQL_BIN="/Applications/MAMP/Library/bin/mysql80/bin"
MAMP_MYSQL_ARGS=(-uroot -proot -h127.0.0.1 -P8889)

DRY="${DRY:-0}"

log() { printf '%s %s\n' "$(date +%H:%M:%S)" "$*" >&2; }
die() { log "ERROR: $*"; exit 1; }
run() { if [ "1" = "$DRY" ]; then log "DRY: $*"; else "$@"; fi; }

# site_row <host> : load one inventory row into SITE_* variables.
site_row() {
	local row
	row="$(awk -F'\t' -v h="$1" '$0 !~ /^#/ && $1 == h { print; exit }' "$SITES_TSV")"
	[ -n "$row" ] || die "unknown site '$1' (not in $SITES_TSV)"
	IFS=$'\t' read -r SITE_HOST SITE_FOLDER SITE_PHP SITE_DB SITE_PROTECTED SITE_NOTES <<<"$row"
	SITE_PATH="$SITES_DIR/$SITE_FOLDER"
	SITE_URL="https://$SITE_HOST.$TLD"
}

# all_hosts : print every host in inventory order.
all_hosts() { awk -F'\t' '$0 !~ /^#/ && NF >= 5 { print $1 }' "$SITES_TSV"; }

# php_bin php@7.4 -> /opt/homebrew/opt/php@7.4/bin/php
php_bin() { printf '%s/opt/%s/bin/php\n' "$BREW_PREFIX" "$1"; }

# wp_site <php formula> <site path> <wp args...> : WP-CLI under the site's PHP, core only.
wp_site() {
	local php="$1" path="$2"
	shift 2
	"$(php_bin "$php")" "$BREW_PREFIX/bin/wp" --path="$path" --skip-plugins --skip-themes "$@"
}

mysql_new()     { "$BREW_PREFIX/opt/mysql@8.4/bin/mysql" -uroot "$@"; }
mysql_old()     { "$MAMP_MYSQL_BIN/mysql" "${MAMP_MYSQL_ARGS[@]}" "$@" 2> >(grep -v 'Using a password' >&2); }
mysqldump_old() { "$MAMP_MYSQL_BIN/mysqldump" "${MAMP_MYSQL_ARGS[@]}" "$@" 2> >(grep -v 'Using a password' >&2); }

# sql_quote <string> : escape for a single-quoted MySQL literal.
sql_quote() { printf '%s' "$1" | sed "s/\\\\/\\\\\\\\/g; s/'/\\\\'/g"; }
```

```php
<?php
/**
 * Valet driver for a WordPress subdirectory multisite.
 * Mirrors the two rewrite rules WordPress core generates for subdirectory installs.
 * Installed by local-devstack as <site>/LocalValetDriver.php.
 */
class LocalValetDriver extends WordPressValetDriver {

	/**
	 * Strip the sub-site prefix from core paths: /automator/wp-admin/x -> /wp-admin/x
	 */
	private function strip_subsite_prefix( string $uri ): string {
		$uri = preg_replace( '#^/[_0-9a-zA-Z-]+(/wp-(content|admin|includes)/.*)$#', '$1', $uri );
		return preg_replace( '#^/[_0-9a-zA-Z-]+(/.*\.php)$#', '$1', $uri );
	}

	public function isStaticFile( $sitePath, $siteName, $uri ) {
		return parent::isStaticFile( $sitePath, $siteName, $this->strip_subsite_prefix( $uri ) );
	}

	public function frontControllerPath( $sitePath, $siteName, $uri ) {
		return parent::frontControllerPath( $sitePath, $siteName, $this->strip_subsite_prefix( $uri ) );
	}
}
```

- [ ] **Step 2: `bootstrap.sh`**

```bash
#!/usr/bin/env bash
# local-devstack bootstrap: idempotent. Run it again any time.
# Needs your sudo password once (valet install / valet trust); after that brew+valet are passwordless.
set -euo pipefail

REPO_DIR="$(cd "$(dirname "${BASH_SOURCE[0]}")" && pwd)"
BREW_PREFIX="$(brew --prefix)"
COMPOSER_BIN="$HOME/.composer/vendor/bin"
VALET_BIN="$COMPOSER_BIN/valet"
VALET_HOME="$HOME/.config/valet"
DEFAULT_PHP="php@8.4"
PHP_VERSIONS=(8.4 7.4)

log()  { printf '\033[1;34m==>\033[0m %s\n' "$*"; }
ok()   { printf '\033[1;32m ✓ \033[0m %s\n' "$*"; }
warn() { printf '\033[1;33m ! \033[0m %s\n' "$*"; }

ensure_brew() {
	command -v brew > /dev/null || { echo "Homebrew missing: https://brew.sh"; exit 1; }
	xcode-select -p > /dev/null 2>&1 || { echo "Xcode / Command Line Tools missing"; exit 1; }
	ok "Homebrew $(brew --version | head -1 | awk '{print $2}') at $BREW_PREFIX"
}

ensure_formulae() {
	log "Homebrew formulae"
	brew tap shivammathur/php > /dev/null
	if brew help trust > /dev/null 2>&1; then brew trust shivammathur/php > /dev/null 2>&1 || true; fi
	brew bundle --file="$REPO_DIR/Brewfile" --no-upgrade
	# mysql@8.4 is keg-only; wp db export/import want mysql/mysqldump on PATH.
	brew link --force --overwrite mysql@8.4 > /dev/null 2>&1 || true
	ok "formulae present"
}

ensure_php_ini() {
	log "PHP conf.d drop-ins"
	local v dst
	for v in "${PHP_VERSIONS[@]}"; do
		dst="$BREW_PREFIX/etc/php/$v/conf.d/zz-uo-dev.ini"
		[ -d "$(dirname "$dst")" ] || { warn "no conf.d for PHP $v (formula not installed?)"; continue; }
		if ! cmp -s "$REPO_DIR/php/zz-uo-dev.ini" "$dst"; then
			cp "$REPO_DIR/php/zz-uo-dev.ini" "$dst"; ok "installed $dst"
		else
			ok "up to date: $dst"
		fi
	done
}

ensure_composer_path() {
	log "Composer global bin on PATH"
	local line='export PATH="$HOME/.composer/vendor/bin:$PATH"'
	grep -qF "$line" "$HOME/.zshrc" 2> /dev/null || { printf '\n# local-devstack: Laravel Valet\n%s\n' "$line" >> "$HOME/.zshrc"; ok "added to ~/.zshrc"; }
	export PATH="$COMPOSER_BIN:$PATH"
}

# add_ipv6_listen <nginx conf> : Valet 4.12.0 answers dnsmasq with ::1 but only listens on 127.0.0.1 (laravel/valet #1558).
add_ipv6_listen() {
	local f="$1"
	[ -f "$f" ] || return 0
	grep -q 'listen \[::1\]' "$f" && return 0
	perl -0pi -e 's/^(\s*)listen 127\.0\.0\.1:(\d+)( ssl)?;/$&\n$1listen [::1]:$2$3;/mg' "$f"
	ok "IPv6 listen added: $f"
}

ensure_valet() {
	log "Laravel Valet"
	if [ ! -x "$VALET_BIN" ]; then
		composer global require laravel/valet --quiet
		ok "valet installed via composer"
	fi
	# Patch stubs before install/secure so every generated conf carries the IPv6 listen.
	add_ipv6_listen "$HOME/.composer/vendor/laravel/valet/cli/stubs/valet.conf"
	add_ipv6_listen "$HOME/.composer/vendor/laravel/valet/cli/stubs/secure.valet.conf"
	add_ipv6_listen "$HOME/.composer/vendor/laravel/valet/cli/stubs/isolated.valet.conf"
	add_ipv6_listen "$HOME/.composer/vendor/laravel/valet/cli/stubs/secure.isolated.valet.conf"
	if [ ! -f "$VALET_HOME/config.json" ]; then
		warn "valet install needs your sudo password"
		"$VALET_BIN" install
	fi
	if [ ! -f /etc/sudoers.d/valet ]; then
		warn "valet trust needs your sudo password (once)"
		"$VALET_BIN" trust
	fi
	ok "valet $("$VALET_BIN" --version | awk '{print $NF}') installed and trusted"
	add_ipv6_listen "$BREW_PREFIX/etc/nginx/valet/valet.conf"
	local f
	for f in "$VALET_HOME"/Nginx/*; do add_ipv6_listen "$f"; done
	"$VALET_BIN" use "$DEFAULT_PHP" --force > /dev/null
	ok "default PHP $DEFAULT_PHP"
	"$VALET_BIN" restart > /dev/null
}

ensure_services() {
	log "Data services"
	brew services start mysql@8.4 > /dev/null 2>&1 || true
	ok "mysql@8.4 $(brew services list | awk '$1=="mysql@8.4"{print $2}')"
	if lsof -nP -iTCP:1025 -sTCP:LISTEN 2> /dev/null | grep -qv mailpit && ! lsof -nP -iTCP:1025 -sTCP:LISTEN 2> /dev/null | grep -q mailpit; then
		warn "port 1025 is held by $(lsof -nP -iTCP:1025 -sTCP:LISTEN | awk 'NR==2{print $1}') (MAMP MailHog?) — Mailpit not started; mail from Valet sites still lands there via SMTP"
	else
		brew services start mailpit > /dev/null 2>&1 || true
		ok "mailpit $(brew services list | awk '$1=="mailpit"{print $2}')"
	fi
}

ensure_dashboard() {
	log "Dashboard"
	if [ ! -L "$VALET_HOME/Sites/dashboard" ]; then
		( cd "$REPO_DIR/dashboard" && "$VALET_BIN" link dashboard > /dev/null )
	fi
	[ -f "$VALET_HOME/Certificates/dashboard.test.crt" ] || "$VALET_BIN" secure dashboard > /dev/null
	ok "https://dashboard.test"
}

ensure_brew
ensure_formulae
ensure_php_ini
ensure_composer_path
ensure_valet
ensure_services
ensure_dashboard
log "Done. Next: bin/migrate-site <host>  (pilot: cleantest, clean-automator)"
```

```bash
#!/usr/bin/env bash
# migrate-site <host> [--json] [--dry-run] [--i-have-a-backup]
# One MAMP host -> https://<host>.test on Valet + mysql@8.4. Idempotent: re-running is a no-op.
source "$(cd "$(dirname "${BASH_SOURCE[0]}")" && pwd)/lib.sh"

HOST="" ; JSON=0 ; BACKUP_FLAG=0
for arg in "$@"; do
	case "$arg" in
		--json) JSON=1 ;;
		--dry-run) DRY=1 ;;
		--i-have-a-backup) BACKUP_FLAG=1 ;;
		--*) die "unknown flag $arg" ;;
		*) HOST="$arg" ;;
	esac
done
[ -n "$HOST" ] || die "usage: migrate-site <host> [--json] [--dry-run] [--i-have-a-backup]"

site_row "$HOST"
[ -d "$SITE_PATH" ] || die "folder missing: $SITE_PATH"
if [ "yes" = "$SITE_PROTECTED" ] && [ "1" != "$BACKUP_FLAG" ]; then
	die "$SITE_HOST is a PROTECTED site (handoff 6.1). Take and verify a fresh backup, then re-run with --i-have-a-backup."
fi
mkdir -p "$LOG_DIR"
exec 2> >(tee -a "$LOG_DIR/$SITE_HOST.log" >&2)
log "=== migrate-site $SITE_HOST ($SITE_FOLDER, $SITE_PHP, db=$SITE_DB) DRY=$DRY"

# 1. Link (explicit, never parked).
step_link=skipped
if [ ! -L "$VALET_HOME/Sites/$SITE_HOST" ]; then
	( cd "$SITE_PATH" && run "$VALET_BIN" link "$SITE_HOST" )
	step_link=linked
fi
log "link: $step_link"

# 2. Per-site PHP: .valetrc for `valet php`, isolate for FPM.
step_isolate=default
if [ "$SITE_PHP" != "$DEFAULT_PHP" ]; then
	if [ "$(cat "$SITE_PATH/.valetrc" 2> /dev/null)" != "php=$SITE_PHP" ]; then
		[ "1" = "$DRY" ] || printf 'php=%s\n' "$SITE_PHP" > "$SITE_PATH/.valetrc"
	fi
	if "$VALET_BIN" isolated 2> /dev/null | grep -q "^| *$SITE_HOST "; then
		step_isolate="already $SITE_PHP"
	else
		run "$VALET_BIN" isolate "$SITE_PHP" --site="$SITE_HOST"
		step_isolate="isolated $SITE_PHP"
	fi
fi
log "php: $step_isolate"

# 3. HTTPS.
step_secure=already
if [ ! -f "$VALET_HOME/Certificates/$SITE_HOST.$TLD.crt" ]; then
	run "$VALET_BIN" secure "$SITE_HOST"
	step_secure=secured
fi
log "https: $step_secure"

# Non-WordPress sites stop here.
if [ "-" = "$SITE_DB" ] || [ ! -f "$SITE_PATH/wp-config.php" ]; then
	log "not a WordPress site; done"
	[ "1" = "$JSON" ] && jq -n --arg host "$SITE_HOST" --arg url "$SITE_URL" '{host:$host,url:$url,type:"non-wp",ok:true}'
	exit 0
fi

wp() { wp_site "$SITE_PHP" "$SITE_PATH" "$@"; }

# 4. Database: copy MAMP -> mysql@8.4 once; recreate the site's DB user.
step_db=already
if [ "0" = "$(mysql_new -N -e "SELECT COUNT(*) FROM information_schema.SCHEMATA WHERE SCHEMA_NAME='$(sql_quote "$SITE_DB")'")" ]; then
	dump="$LOG_DIR/$SITE_DB.$(date +%Y%m%d-%H%M%S).sql"
	if [ "1" = "$DRY" ]; then
		log "DRY: mysqldump $SITE_DB -> $dump ; mysql < $dump"
	else
		mysqldump_old --single-transaction --routines --triggers --default-character-set=utf8mb4 --databases "$SITE_DB" > "$dump"
		mysql_new < "$dump"
		old_n="$(mysql_old -N -e "SELECT COUNT(*) FROM information_schema.TABLES WHERE TABLE_SCHEMA='$SITE_DB'")"
		new_n="$(mysql_new -N -e "SELECT COUNT(*) FROM information_schema.TABLES WHERE TABLE_SCHEMA='$SITE_DB'")"
		[ "$old_n" = "$new_n" ] || die "table count mismatch after import: MAMP=$old_n new=$new_n"
		step_db="imported $new_n tables"
	fi
fi
log "db: $step_db"

db_user="$(wp config get DB_USER)"
db_pass="$(wp config get DB_PASSWORD)"
u="$(sql_quote "$db_user")"; p="$(sql_quote "$db_pass")"; d="$(printf '%s' "$SITE_DB" | sed 's/`/``/g')"
run mysql_new -e "CREATE USER IF NOT EXISTS '$u'@'localhost' IDENTIFIED BY '$p'; CREATE USER IF NOT EXISTS '$u'@'127.0.0.1' IDENTIFIED BY '$p'; GRANT ALL ON \`$d\`.* TO '$u'@'localhost', '$u'@'127.0.0.1'; FLUSH PRIVILEGES;"
log "db user: $db_user ensured"

# 5. DB_HOST -> 127.0.0.1 (must happen BEFORE search-replace, or WP-CLI would edit MAMP's copy).
step_dbhost=already
if [ "127.0.0.1" != "$(wp config get DB_HOST)" ]; then
	run wp config set DB_HOST 127.0.0.1 --quiet
	step_dbhost="set 127.0.0.1"
fi
log "DB_HOST: $step_dbhost"
[ "1" = "$DRY" ] || wp db check --quiet > /dev/null || die "WordPress cannot reach $SITE_DB on 127.0.0.1"

# 6. URLs.
is_ms="$(wp config get MULTISITE 2> /dev/null || echo 0)"
sr_flags=(--all-tables --skip-columns=guid --report-changed-only --quiet)
[ "1" = "$is_ms" ] && sr_flags+=(--network --url="$SITE_URL")
run wp search-replace "https://$SITE_HOST:8890" "$SITE_URL" "${sr_flags[@]}"
run wp search-replace "http://$SITE_HOST:8888"  "$SITE_URL" "${sr_flags[@]}"
run wp search-replace "$SITE_HOST:8890"         "$SITE_HOST.$TLD" "${sr_flags[@]}"
if [ "1" = "$is_ms" ]; then
	run wp config set DOMAIN_CURRENT_SITE "$SITE_HOST.$TLD" --quiet
	if [ "1" != "$(wp config get SUBDOMAIN_INSTALL 2> /dev/null || echo 0)" ]; then
		run cp "$REPO_DIR/drivers/LocalValetDriver-multisite-subdir.php" "$SITE_PATH/LocalValetDriver.php"
	fi
fi
run wp cache flush --quiet 2> /dev/null || true
log "urls: -> $SITE_URL"

# 7. Local SSL mu-plugin.
mkdir -p "$SITE_PATH/wp-content/mu-plugins"
if ! cmp -s "$REPO_DIR/mu-plugins/uo-local-ssl.php" "$SITE_PATH/wp-content/mu-plugins/uo-local-ssl.php"; then
	run cp "$REPO_DIR/mu-plugins/uo-local-ssl.php" "$SITE_PATH/wp-content/mu-plugins/uo-local-ssl.php"
fi
log "mu-plugin: uo-local-ssl.php in place"

# 8. Smoke tests. /usr/bin/curl uses the keychain, so no -k: a cert-trust failure shows up as 000.
if [ "1" = "$DRY" ]; then log "DRY: smoke skipped"; exit 0; fi
code4="$(/usr/bin/curl -4 -s -o /dev/null -w '%{http_code}' "$SITE_URL/")"
code6="$(/usr/bin/curl -6 -s -o /dev/null -w '%{http_code}' "$SITE_URL/")"
login="$(/usr/bin/curl -s "$SITE_URL/wp-login.php" | grep -c 'loginform' || true)"
siteurl="$(wp option get siteurl)"
powered="$(/usr/bin/curl -sI "$SITE_URL/" | awk 'tolower($1)=="x-powered-by:"{print $2}' | tr -d '\r')"
loop="$(wp eval 'echo is_wp_error( wp_remote_get( home_url( "/wp-json/" ) ) ) ? "ERR" : "OK";')"
ok=true
[ "200" = "$code4" ] && [ "200" = "$code6" ] && [ "$login" -ge 1 ] && [ "$siteurl" = "$SITE_URL" ] && [ "OK" = "$loop" ] || ok=false
log "smoke: ipv4=$code4 ipv6=$code6 login=$login siteurl=$siteurl fpm=$powered loopback=$loop ok=$ok"
if [ "1" = "$JSON" ]; then
	jq -n --arg host "$SITE_HOST" --arg url "$SITE_URL" --arg php "$SITE_PHP" --arg fpm "$powered" \
		--arg link "$step_link" --arg isolate "$step_isolate" --arg secure "$step_secure" --arg db "$step_db" --arg dbhost "$step_dbhost" \
		--argjson ipv4 "$code4" --argjson ipv6 "$code6" --argjson login "$login" --arg siteurl "$siteurl" --arg loopback "$loop" --argjson ok "$ok" \
		'{host:$host,url:$url,php:$php,fpm:$fpm,steps:{link:$link,isolate:$isolate,secure:$secure,db:$db,db_host:$dbhost},smoke:{ipv4:$ipv4,ipv6:$ipv6,login_form:$login,siteurl:$siteurl,loopback:$loopback},ok:$ok}'
fi
[ "true" = "$ok" ]
```

```bash
#!/usr/bin/env bash
# migrate-all [--only host1,host2] [--include-protected] [--dry-run]
# Runs migrate-site over the inventory; protected sites are skipped unless asked; never aborts on one failure.
source "$(cd "$(dirname "${BASH_SOURCE[0]}")" && pwd)/lib.sh"

ONLY="" ; INCLUDE_PROTECTED=0 ; EXTRA=()
for arg in "$@"; do
	case "$arg" in
		--only=*) ONLY="${arg#--only=}" ;;
		--include-protected) INCLUDE_PROTECTED=1 ;;
		--dry-run) EXTRA+=(--dry-run) ;;
		*) die "unknown argument $arg" ;;
	esac
done

pass=() ; fail=() ; skip=()
for host in $(all_hosts); do
	site_row "$host"
	if [ -n "$ONLY" ] && ! printf ',%s,' "$ONLY" | grep -q ",$host,"; then continue; fi
	if [ "yes" = "$SITE_PROTECTED" ] && [ "1" != "$INCLUDE_PROTECTED" ]; then skip+=("$host"); continue; fi
	flags=("${EXTRA[@]}")
	[ "yes" = "$SITE_PROTECTED" ] && flags+=(--i-have-a-backup)
	if "$REPO_DIR/bin/migrate-site" "$host" "${flags[@]}"; then pass+=("$host"); else fail+=("$host"); fi
done
jq -n --argjson pass "$(printf '%s\n' "${pass[@]:-}" | jq -R . | jq -s 'map(select(. != ""))')" \
      --argjson fail "$(printf '%s\n' "${fail[@]:-}" | jq -R . | jq -s 'map(select(. != ""))')" \
      --argjson skipped "$(printf '%s\n' "${skip[@]:-}" | jq -R . | jq -s 'map(select(. != ""))')" \
      '{pass:$pass,fail:$fail,skipped_protected:$skipped}'
[ "${#fail[@]}" -eq 0 ]
```

### Task 9: `bin/stack-status`

**Files:**
- Create: `bin/stack-status` (executable)

**Interfaces:**
- Produces: `stack-status [--json]` → JSON `{services:[{name,status}], sites:[{name,php,secured}], ports:{80,443,3306,1025,8025}, mysql:{version,qps}, mail:{backend,total}}`; the future menu-bar app polls this.

- [ ] **Step 1: Write it**

```bash
#!/usr/bin/env bash
# stack-status [--json] : one JSON blob describing the local stack (polled by the menu-bar app).
source "$(cd "$(dirname "${BASH_SOURCE[0]}")" && pwd)/lib.sh"

services="$( (sudo -n brew services list --json 2> /dev/null || brew services list --json) \
	| jq '[.[] | select(.name | test("^(nginx|dnsmasq|php(@[0-9.]+)?|mysql@8.4|mailpit)$")) | {name, status}]')"

sites="$(for l in "$VALET_HOME"/Sites/*; do
	[ -L "$l" ] || continue
	n="$(basename "$l")"; php=default
	conf="$VALET_HOME/Nginx/$n.$TLD"
	[ -f "$conf" ] && php="$(grep -oE 'valet[0-9]+\.sock' "$conf" | head -1 | sed -E 's/valet([0-9])([0-9]+)\.sock/\1.\2/')"
	secured=false; [ -f "$VALET_HOME/Certificates/$n.$TLD.crt" ] && secured=true
	jq -n --arg name "$n" --arg php "${php:-default}" --argjson secured "$secured" '{name:$name,php:$php,secured:$secured}'
done | jq -s .)"

ports="$(for p in 80 443 3306 1025 8025; do
	owner="$(lsof -nP -iTCP:$p -sTCP:LISTEN 2> /dev/null | awk 'NR==2{print $1}')"
	jq -n --arg p "$p" --arg o "${owner:-}" '{($p): (if $o == "" then null else $o end)}'
done | jq -s add)"

mysql_json='{"version":null,"qps":null}'
if st="$("$BREW_PREFIX/opt/mysql@8.4/bin/mysqladmin" -uroot status 2> /dev/null)"; then
	up="$(sed -E 's/.*Uptime: ([0-9]+).*/\1/' <<<"$st")"; q="$(sed -E 's/.*Questions: ([0-9]+).*/\1/' <<<"$st")"
	v="$(mysql_new -N -e 'SELECT VERSION()')"
	mysql_json="$(jq -n --arg v "$v" --argjson qps "$(awk -v q="$q" -v u="$up" 'BEGIN{printf "%.2f", (u>0)?q/u:0}')" '{version:$v,qps:$qps}')"
fi

mail_json='{"backend":null,"total":null}'
if t="$(curl -s -m 1 http://localhost:8025/api/v1/messages?limit=1 | jq -e '.total' 2> /dev/null)"; then
	mail_json="$(jq -n --argjson t "$t" '{backend:"mailpit",total:$t}')"
elif t="$(curl -s -m 1 http://localhost:8025/api/v2/messages?limit=1 | jq -e '.total' 2> /dev/null)"; then
	mail_json="$(jq -n --argjson t "$t" '{backend:"mailhog",total:$t}')"
fi

jq -n --argjson services "$services" --argjson sites "$sites" --argjson ports "$ports" --argjson mysql "$mysql_json" --argjson mail "$mail_json" \
	'{generated_at: now | todate, services:$services, sites:$sites, ports:$ports, mysql:$mysql, mail:$mail}'
```
